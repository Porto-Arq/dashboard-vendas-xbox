Desafio de Dashboard de Vendas - Xbox Game Pass

Projeto focado em transformar dados brutos de vendas de assinaturas (Core, Standard e Ultimate) em gráficos visuais no Microsoft Excel para auxiliar na tomada de decisões.

Conteúdo:
- Base de dados de assinantes tratada.
- Tabelas dinâmicas e Dashboard interativo.

Para abrir:
Baixe o arquivo Excel deste repositório e abra no Microsoft Excel.
